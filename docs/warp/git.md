**#Git - zestaw podstawowych komend**



\##1 git clone



przykład użycia: git clone URL



opis: Pobieranie repozytorium i utworzenie lokalnego katalogu



\##2 git status



przykład użycia: git status



opis: Sprawdzenie gałęzi oraz plików zmienionych i przygotowanych



\##3 git add



przykład użycia: git add docs/warp/git.md



opis: Dodanie konkretnego pliku do obszaru staging.



\##4 git commit



przykład użycia: git commit -m "docs: add Git cheatsheet"



opis: Zapis przygotowanych zmian z czytelnym komunikatem



\##5 git push



przykład użycia: git push -u origin feature/git-cheatsheet



opis: Publikacja nowej gałęzi i ustawienie śledzenia



\##6 git pull



przykład użycia: git pull --ff-only origin main



opis: Pobranie zmian bez tworzenia nieoczekiwanego merge commita



\##7 git fetch



przykład użycia: git fetch origin



opis: Pobranie informacji o zmianach bez modyfikowania plików roboczych



\##8 git branch



przykład użycia: git branch



opis: Wyświetlenie lokalnych gałęzi i oznaczenie aktywnej



\##9 git switch



przykład użycia: git switch -c feature/nazwa



opis: Utworzenie gałęzi roboczej i przełączenie na nią



\##10 git log



przykład użycia: git log --oneline -5



opis: Skrócony podgląd pięciu ostatnich commitów
