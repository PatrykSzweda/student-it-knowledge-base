## Instrukcja korzystania
1. Otwórz folder wybranego przedmiotu.
2. Zapoznaj się z dostępnymi materiałami edukacyjnymi.
3. Korzystaj ze ściąg jako materiałów pomocniczych podczas nauki i powtarzania zagadnień.
4. W razie potrzeby pobierz wybrane pliki na swoje urządzenie.
5. Materiały można przeglądać bezpośrednio na GitHubie lub lokalnie po sklonowaniu repozytorium.
