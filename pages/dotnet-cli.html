Instrukcja .NET CLI

Strona główna Bash .NET CLI

Wprowadzenie

.NET CLI to narzędzie wiersza poleceń służące do tworzenia, budowania i uruchamiania aplikacji .NET.

Podstawowe komendy

Komendy .NET CLI
Polecenie Opis
dotnet --version Wyświetla wersję zainstalowanego .NET SDK.
dotnet --list-sdks Wyświetla zainstalowane wersje SDK.
dotnet new list Wyświetla dostępne szablony projektów.
dotnet new console Tworzy nowy projekt aplikacji konsolowej.
dotnet restore Pobiera zależności projektu.
dotnet build Kompiluje projekt.
dotnet run Uruchamia aplikację.
dotnet clean Usuwa wyniki poprzedniej kompilacji.

Tworzenie i uruchamianie aplikacji

Poniżej znajduje się przykładowa sekwencja poleceń potrzebnych do utworzenia i uruchomienia aplikacji. 

dotnet --version
dotnet --list-sdks
dotnet new list
dotnet new console -n MojaAplikacja
cd MojaAplikacja
dotnet restore
dotnet build
dotnet run
dotnet clean
