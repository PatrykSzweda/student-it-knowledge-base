Komendy Bash

Strona główna

Wprowadzenie

Strona przedstawia podstawowe komendy systemu Linux, ich przykłady oraz zastosowanie.

Zasady bezpiecznej pracy w terminalu

  • Sprawdzaj, w jakim katalogu się znajdujesz.
  • Uważaj przy usuwaniu plików za pomocą rm.
  • Sprawdzaj poprawność ścieżek.
  • Twórz kopie zapasowe ważnych plików.

Podstawowe komendy

Komendy Linux
Polecenie Przykład Opis
pwd pwd Wyświetla aktualną ścieżkę.
ls ls -l Wyświetla pliki i katalogi.
cd cd docs Zmienia katalog.
mkdir mkdir folder Tworzy katalog.
touch touch plik.txt Tworzy pusty plik.
cp cp plik.txt kopia.txt Kopiuje plik.
mv mv plik.txt nowy.txt Przenosi lub zmienia nazwę pliku.
rm rm plik.txt Usuwa plik.
cat cat plik.txt Wyświetla zawartość pliku.
clear clear Czyści ekran terminala.
